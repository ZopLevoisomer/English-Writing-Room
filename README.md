# 高考英语读后续写八股生成器

已完成三个阶段：核心组合工作台、素材库与数据管理、AI 辅助。使用 React、TypeScript、Vite、Tailwind CSS，无后端。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。生产构建：`npm run build`；本地预览构建：`npm run preview`。

本机验收中，开发服务的源码模块请求在刷新时曾收到空的 HTTP 204 响应，原因尚未确定。
如遇刷新白屏，可运行 `npm run build` 后运行 `npm run preview`，使用生产预览；该方式已通过完整刷新恢复测试。

## 已实现

- 8 个板块、16 个主题、32 条内置示例句的三级浏览。
- 标题、原文和两段段首句编辑。
- 模板句加入指定段落、编辑、删除、上下排序和跨段移动。
- 在任意内容块前后插入普通连接文字；连接文字同样可排序和跨段移动。
- 模板句始终保留高亮和来源标记。
- 当前作文通过 localStorage 自动保存，刷新恢复；读取或保存失败时显示提示。
- 板块、主题、模板句新增、编辑、删除；删除父级素材时确认级联删除。
- 英文、中文、标签、板块及主题搜索，收藏和收藏筛选。
- 模板句支持逗号分隔的简单标签，重复标签自动去重。
- JSON 全量导出、校验后覆盖导入、恢复默认素材库。
- 第一阶段草稿自动迁移；素材修改或删除不改变已有作文，模板块保留加入时的来源名称。

- API Base URL、Model、API Key 配置；可选择是否在本机保存 Key。
- AI 推荐现有模板主题、串联作文、润色作文、语法检查。
- 串联与润色结果先预览再确认应用，保留模板原文、身份、来源、段落与顺序。
- 请求失败、取消、超时不改变作文；生成后继续编辑会使旧预览失效。

数据只存在当前浏览器、当前站点来源下；清除站点数据或切换浏览器、域名、端口将无法访问原草稿。

## 素材管理与备份

在“素材库管理”中填写板块名称，点击“新增板块”；在该板块下填写主题名称并新增主题，然后填写英文、中文释义与标签添加句子。
“保存板块名称”和“保存主题名称”用于重命名当前选择。编辑句子时，可通过左侧选择更改其归属。
搜索或勾选“只看收藏”时，结果覆盖全部板块；选择板块或主题可回到按主题浏览。

“设置”中导出 JSON 后可离线保存。导入先检查 version、字段类型、重复 ID、主题与句子归属，再显示数量摘要；点击“确认覆盖导入”才替换本地数据。
写入失败时不应用导入内容。恢复默认素材库仅替换素材，保留作文。

数据继续保存在原 localStorage 键 `english-continuation:v1`。新格式包含 `version: 1`、`categories`、`topics`、`sentences`、`essays`、`currentEssayId`、`settings`；支持读取第一阶段的 `{ version: 1, essay }`。
备份包含全部已保存作文；导入多篇作文后，工作台会显示作文切换选项。导出设置保留 `baseUrl`、`model`，将 `saveApiKey` 设为 false，始终排除 API Key。覆盖导入忽略文件中的 Key 并清除当前页面的旧 Key，需重新填写，避免将旧凭据发送到备份中的其他服务地址。

## 完稿阅读（Submit）

在两段编辑区下方点击“Submit · 生成全文”，即可打开书页式全文阅读窗口：按现有段落和内容块顺序，用空格衔接段首句、模板句与普通文字。正文有独立边框；模板句使用主题色底纹和下划线，题目段首句保持普通样式。原题可在正文框外展开查看。
此操作不调用 AI、不增写内容、不改动草稿。点击“返回编辑”或按 Escape 关闭；修改后再次 Submit 可生成最新全文。

## 外观设置

页眉提供日间／夜间切换，以及书林绿、墨水蓝、蔷薇紫、旧书棕四种主题色。配色覆盖工作台、素材管理、设置、AI 预览和全文阅读，模板句与多色标签在夜间仍保留高亮。默认使用日间书林绿。
外观选择自动保存到本机，刷新后恢复，也随 JSON 备份导出和导入；保存 API 设置不会覆盖外观选择。

## AI 使用

1. 在“设置 → API 设置”填写 Base URL、Model 和服务所需的 API Key，点击“保存 API 设置”。
2. 回到工作台，填写原文 / 题目及两个段首句，点击“推荐模板主题”。推荐只使用素材库现有主题；点击“查看该主题”，再自行选择模板句。
3. 选句并补充必要文字后，点击“串联作文”。右侧显示两段预览，可展开生成前的作文作比较。点击“确认应用到作文”才替换正文。
4. “润色作文”同样需要预览确认。“语法检查”只显示原文、建议和原因，由用户核对后手动修改。

AI 定位为高考英语优秀作文水平，提示词要求保持剧情、避免大幅重写。程序会拒绝遗漏、改写、跨段移动、重排或重复原模板块的输出；需要修改模板本身时，可先在编辑区手动修改。
普通文字的语义与情节仍需用户核对预览，程序不能自动证明 AI 保持了全部原意。

### 接口与 Key

- 统一请求入口为 `src/ai.ts`，通过 `POST /chat/completions` 发送 `model` 和 `messages`，读取 `choices[0].message.content`。接口格式参考 [OpenAI 官方文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。
- Base URL 应包含服务要求的路径，例如 `https://你的服务地址/v1`。程序在末尾追加 `/chat/completions`，也支持直接填写完整端点。使用 HTTPS；本机 localhost、127.0.0.1、[::1] 服务可用 HTTP。
- Model 需填写服务商实际支持的名称。服务须支持浏览器 CORS、非流式 Chat Completions，并能够按提示输出 JSON。未强制使用供应商特定的结构化输出参数。
- API Key 默认仅保存在当前页面内存中，刷新后清空；勾选保存后，以明文写入当前浏览器 localStorage。取消勾选并保存会删除已持久化的 Key。无需鉴权的本机服务可留空。
- 只有点击 AI 操作才发送请求。Key 只用于授权请求头，不加入提示词或备份。推荐发送题目、段首句和板块主题列表；其他操作发送题目与当前作文，不发送其他作文。
- 单次请求超时为 90 秒，可主动取消。切换离开工作台或切换作文会取消未完成请求并清除预览。失败会提示错误，不自动重试，不修改正文。

## 验证

```sh
npm run build
npm test
```

`npm test` 会先构建，再对生产预览页面测试。端到端测试默认使用本机 Google Chrome（`playwright.config.ts` 中的 `channel: 'chrome'`）。
测试覆盖选句、排序、跨段移动、连接文字、编辑后模板身份、刷新恢复、旧草稿迁移、自建素材搜索与使用、导入导出、级联删除、空库、错误备份拒绝和存储失败保护。
AI 测试覆盖推荐、选句、串联与润色预览确认、语法建议、无效输出拒绝、过期预览、取消与超时、Key 持久化与导出排除，以及窄屏操作。
测试使用独立端口 4183，日常预览使用 4173，可同时运行。

2026-09-27 外观更新验收：生产构建通过，20 项已有功能测试及 2 项新增外观测试通过；外观测试覆盖四种主题的日夜切换、刷新记忆、备份恢复、API 设置兼容、全文阅读与窄屏布局，并检查夜间页面截图。
AI 测试拦截请求并返回模拟响应，不消耗真实 API 额度；尚未使用真实服务凭据验证连通性、模型输出质量与供应商兼容性。

## 结构

- `src/data.ts`：默认板块、主题、示例句。
- `src/types.ts`：素材及作文 Block 数据结构。
- `src/persistence.ts`：本地数据读写、旧草稿迁移、备份校验、导出字段筛选。
- `src/App.tsx`：素材浏览和双段落工作台。
- `src/LibraryManager.tsx`：板块、主题与句子管理。
- `src/DataSettings.tsx`：导入导出、恢复默认素材。
- `src/ApiSettingsForm.tsx`：API 配置及 Key 保存选项。
- `src/ai.ts`：四项 AI 请求、提示词、结果校验、超时与错误处理。
- `src/AiPanel.tsx`：操作入口、结果预览、确认应用和过期结果保护。
- `src/styles.css`：界面样式及响应式布局。
- `tests/workbench.spec.ts`：真实浏览器端到端验收。
- `tests/library.spec.ts`：第二阶段端到端验收及数据兼容回归。
- `tests/ai.spec.ts`：第三阶段模拟 API 端到端验收。

需求来源为根目录 `agent.md` 和 `agent-1.md`，第三阶段完成后停止扩展。
